3. APIS SOPORTADAS
================================================================================

1. MOCK CLIENT (Desarrollo Gratuito)
   - Latencia: 200-300ms simulada
   - Precio: Gratis
   - Setup: Inmediato (sin API keys)
   - Ideal para: Desarrollo y testing

2. REPLICATE API (Producción)
   - Latencia: 5-15 segundos
   - Precio: $0.01 por predicción (~$30-100/mes)
   - Modelos: IDM-VTON, Cat-VTON, OOTDiff
   - Ideal para: MVP y producción inicial

3. FASHN.AI (Real-time)
   - Latencia: 1-3 segundos
   - Precio: Variable (contactar)
   - Especializado en VTON
   - Ideal para: Experiencia real-time

4. DECART AI / ANYWEAR (Enterprise)
   - Latencia: <1 segundo (WebRTC)
   - Precio: $500+ (custom)
   - Máxima calidad
   - Ideal para: Soluciones enterprise

CAMBIAR ENTRE APIS:
Solo modifica una variable de entorno:
  NEXT_PUBLIC_VTON_PROVIDER=mock|replicate|fashn|decart

5. ARQUITECTURA TÉCNICA
================================================================================

STACK TECNOLÓGICO:
- Frontend: Next.js 14 (React 18)
- Lenguaje: TypeScript 5
- Estilos: Tailwind CSS 3
- Estado: Zustand 4
- API Calls: Fetch API
- Cámara: MediaDevices API
- Canvas: Canvas API

CAPAS:
├── Presentación (Components)
│   ├── VirtualTryOnModal
│   ├── CameraFeed
│   ├── GuidanceOverlay
│   ├── ProductSelector
│   └── CartButton
│
├── Lógica (Hooks)
│   ├── useCamera - Gestiona video
│   ├── useVirtualTryOn - Procesa frames
│   └── useCart - Carrito (Zustand)
│
└── Servicios (API)
    ├── VTONClientBase (clase abstracta)
    ├── MockVTONClient
    ├── ReplicateVTONClient
    └── FashnVTONClient

FLUJO DE DATOS:
Usuario selecciona prenda
    ↓
Captura frame del video (canvas)
    ↓
Envía a API VTON (HTTP/WebSocket)
    ↓
API retorna imagen procesada
    ↓
Renderiza en pantalla
    ↓
Usuario ve la transformación en tiempo real

7. INTEGRACIÓN API REAL (Replicate)
================================================================================

1. Crea cuenta en https://replicate.com
2. Ve a https://replicate.com/account/api-tokens
3. Copia tu API token (r8_xxxxxxxxxxxxx)
4. Edita .env.local:
   NEXT_PUBLIC_VTON_PROVIDER=replicate
   REPLICATE_API_KEY=r8_xxxxxxxxxxxxx
5. Reinicia: npm run dev
6. Prueba - Ahora usa IA real (5-15 segundos por frame)

COSTO:
  • ~$0.01 por predicción
  • 1000 predicciones = $10
  • 10,000 predicciones/mes = $100
